### 3.4 Polaris 的优势（相对三款竞品）

1. **本地优先与隐私**：三款竞品全部强制账号+云端存储；Polaris 数据不出本机、无网络路径，是唯一免账号选项。对隐私敏感/离线/内网场景是独占位。
2. **中文自然语言解析的精度工程**：微软待办 Windows 端不支持中文；滴答与 Todoist 有中文识别但公开文档未见防误吃设计。Polaris 的头尾锚定+14 类掩码+字符守卫+撤销记账（「把下周三的报告提前」不被吃掉、「3点注意事项」不识别）是**可验证的精度差异化**，且识别条逐个可撤销、原文永不改写。
3. **删除安全网完整度品类领先**：Todoist 官方明确无回收站且删除不可撤销（误删靠 Pro 备份 CSV）；微软待办应用内无回收站；滴答垃圾桶需手动开启且保留天数不明。Polaris 的 30 天回收站+恢复+二次确认+Ctrl+Z 撤销+失败回滚全链路有 90 项冒烟断言背书。
4. **主题与无障碍的免费+可验证**：6 套主题全免费（滴答多数锁会员、Todoist 一半锁 Pro），WCAG AA 由脚本逐主题校验且本次复跑全绿；焦点环 ghost 扫描、reduced-motion CDP 仿真、焦点陷阱栈这类工程化无障碍在三款竞品中均无对等的公开承诺（微软有教程但无工程校验）。
5. **完全免费无付费墙**：滴答/Todoist 把提醒、视图、主题等核心进阶功能锁在订阅后；Polaris 全部功能免费且 MIT 开源。
6. **确定性的本地性能与工程质量**：无云同步路径意味着不受竞品公开记录的同步故障/服务端卡顿影响；解析性能有量化守卫；时间边界（DST/23:59）有 23040 个真实时刻的注入时钟校验——这类确定性测试在竞品公开资料中未见对等物。

### 3.5 Polaris 的不足

1. **平台与同步是最大短板**：无移动端、无跨设备同步、无协作——三款竞品全平台覆盖。本地优先是定位取舍，但对多设备用户是硬缺失。
2. **任务组织能力浅**：无子任务、无标签、无附件、无日历/看板视图、无搜索备注；项目管理只有创建+筛选（**无改名/删除/改色/重排**，代码核实）；搜索仅标题子串。滴答/Todoist 的组织深度远超。
3. **提醒可靠性边界**：需应用运行（竞品服务端推送不依赖桌面常驻——Todoist 此点为推断待验证）；不走系统 Toast 意味着不进通知中心、无系统级勿扰协调（双刃剑）；稍后提醒固定 10 分钟无自定义；每任务单提醒（滴答免费 2 个/会员 5 个）。
4. **重复语义缺按完成日推进**：Todoist every! 与滴答「Repeat from Completion Date」支持按实际完成日推算，Polaris 只有按到期日推进。
5. **无统计/回顾**：completed_at 已落库但无任何展示（部分实现）；滴答有统计/番茄/习惯，Todoist 有 Karma/生产力可视化。
6. **分发与信任成本**：安装包未签名（SmartScreen 警告）、无 LICENSE 原文（版权持有人待定）、0.3.0 尚未重新打包（dist 仍是 0.2.x）、无 CI——商业竞品的签名/公证/合规体系成熟得多。
7. **Electron 资源开销**：相对微软待办（第三方称约 45MB 空闲）的原生轻量口碑，Electron 基线内存开销客观存在；Polaris 自身无实测数据（待验证），但 Todoist 同为 Electron 的内存负面口碑是前车之鉴。
8. **生态封闭**：无开放 API、无集成、无导入导出/备份入口（清数据只能删 db 文件）；三款竞品均有 API 或备份体系。

### 3.7 小结

Polaris 不是三款竞品的「功能子集」，而是**不同定位的产品**：它用「本地优先 + 中文解析精度 + 删除安全网 + 免费全功能 + 可验证的键盘/无障碍工程」换取了「多端同步 + 协作 + 组织深度 + 生态」的缺席。在单人、Windows、隐私敏感、键盘驱动的场景里，它的体验完整度足以正面竞争（尤其对微软待办的中文用户——后者 Windows 端连中文 NLP 都没有）；在多设备协作场景里它目前不参与竞争。短期最高杠杆的补齐项（按本报告证据排序）：项目管理闭环（改名/删除）、数据导入导出/备份、完成统计视图（数据已就绪）、签名与 LICENSE（分发信任）。

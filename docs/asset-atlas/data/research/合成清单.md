## 3. 按类别详解

### 3.1 图标：lucide 留任，Phosphor Icons 只 vendored 字形

**为什么不是整库引入。** 调研评分最高的是 Phosphor Icons（1512 基形 × 6 字重，唯一全量线/面同形配对）与 MingCute（2263 对全量配对、中文语义最贴）。但集成轮实测发现：lucide 已有 `Repeat1`，真正的语义缺口只有 `tray` / `tray-arrow-down` / `tray-arrow-up`（Phosphor Icons 是本轮唯一有 tray 语义的库，Tabler 与 MingCute 搜索 tray 均返回空）。为 7 个图标装一个解包 33,027,417 B 的 `@phosphor-icons/react`（registry 实测）并让它进 asar，不划算。仓库已有 `scripts/make-app-icon.mjs` / `make-tray-icon.mjs` 的「生成物入库、不手改」惯例，vendored 完全贴合：`@phosphor-icons/core@2.1.1`（解包 6,476,685 B，集成轮实测）只做 devDependency，构建期把选中的 SVG 编成内联 React 组件，运行时零新增。

**必须知道的几何事实（全部实测）：**
- Phosphor Icons 是 256 网格、**填充化路径**（`fill="currentColor"`，无 stroke），`stroke-width` 对它无效；lucide 是 24 网格真 stroke。16px 下厚度：Phosphor Icons regular 16/256 = 1.00px、bold 1.50px、light 0.75px；lucide 1.75/24 = 1.17px。**regular 是最接近的一档**，混排不会被一眼看穿，但两者内边距不同，要按光学尺寸单独校准。
- core 仓库非 regular 字重的文件名带 `-<weight>` 后缀（`fill/check-circle-fill.svg`），regular 无后缀。
- `check-circle` 的 fill 版是**实心圆盘挖空一个对勾**（反向子路径），对勾是洞、会透出所在行底色——所以**不要**用它整体替换 `.task-check`，保留现有 CSS 圆盘 + `--check-mark` 对勾两层结构。
- 图标粗细实际由 CSS 说了算：`globals.css:374` 的 `.lucide { stroke-width: 1.75 }` 优先级高于 SVG 呈现属性，`<Check strokeWidth={2.6}>` 实际渲染 2.2。统一描边要走 CSS 令牌（见 6.3），不是 prop。

**六套主题适配：** 纯 `currentColor` 继承，零颜色覆盖。teal 只落在「已完成 / 当前选中」两个信号位（`var(--accent)`），其余 `var(--text-secondary)` / `var(--text-tertiary)`。**duotone 字重禁用**——它自带第二层，变相引入第二个信号色。

**备选：** MingCute（Apache-2.0，解包 2,956,439 B，本轮最小的 React 图标包）的 `flag-1..4` 正好映射优先级 0–3、`folder-1/2/3` 贴项目分层，需要时走同一条 vendored 管线；但 `repeat-one` 的形状两次抓取都更像「分享/导出」，**落地前必须肉眼核对**。Tabler / Iconoir / Heroicons / Radix 各有单点优势（真 stroke 可调 / 1.5 轻描边 / 16·20 专绘 / 15 网格像素对齐），但都不足以构成换主集的理由，详见 8.1。

### 3.2 西文字体：全部保留，Geist Sans 是第一顺位备选

12 款候选逐一做过二进制复核（x-height / fvar / GSUB / maxp / 小写均宽），结论是**没有一款比现状更好**：

- **Geist Sans**（OFL-1.1）：与已装 Geist Mono 同源，latin woff2 29,400 B 比现用 Inter latin 48,256 B 省 18,856 B（约 39%，均为实测）。代价：失去 Inter 的 opsz 轴与 cv01–cv14 / zero，x-height 0.530 略低于 Inter 0.5459（中英混排齐平度下降）。**本轮不替换**；若将来决定统一拉丁语气，它是第一顺位，且包内实有 `wght.css` / `wght-italic.css`（调研「只有 index.css」的说法已被核验推翻）。
- **IBM Plex Sans**（OFL-1.1，RFN "Plex"）：本轮 12 款里**唯一带 TrueType hinting**（maxp `maxSizeOfInstructions=3971`，其余全 0），0–9 默认等宽。只有当 Windows 上 11–13px 拉丁被实测反馈发虚时才值得换；x-height 0.516 比 Noto Sans SC 0.543 低约 5%，wght 上限 700。
- **Plus Jakarta Sans**：Manrope 的等价备选，但 winAscent 1296 + winDescent 356 = **1.652em 是 12 款里最高的行高坑**，换上去必须重跑 sub-pixel 行高断言。

**一条方法论纠正（影响所有字体评估）：** 「fvar 默认字重不是 400，不显式设 font-weight 就会拿到 Thin/Light」这个推论在 CSS 下不成立——`@font-face` 声明字重区间后，UA 默认 `font-weight: 400` 落在区间内并生效。现成反例就在项目里：Manrope fvar 默认 200、Noto Sans SC fvar 默认 100，它们并没有渲染成 ExtraLight/Thin。显式写字重仍是好习惯，但不构成否决项。

### 3.3 中文字体：保留 Noto Sans SC，这是结论不是妥协

- **Noto Sans SC / Source Han Sans SC**（OFL-1.1）继续承担全部中文。包 5.3.1 实测 112 文件 / 101 个 woff2 / 4,500,544 B ≈ 4.29 MiB（unpkg `?meta`）；构建产物里 98 片 4,491,296 B。**不要子集化**：任务标题是任意用户输入，98 个分片按 `unicode-range` 惰性加载，4.49 MB 是磁盘成本不是解码成本；裁到 GB2312 会让生僻字掉回系统字体，同一行出现两种字形，省下的空间占安装包不到 2%。
- **MiSans 不可随包分发**（合规轮推翻调研原判）：官方英文 EULA 授权动词只有 use，明文禁止 "redistribute or sell the font software or any copies thereof"，例外只覆盖用字体创作的作品，不覆盖把字体文件打进安装包。
- **HarmonyOS Sans 法律上可用但不采用**：授权明确含 embed/bundle/redistribute **未修改副本**，但禁止任何修改（21.6 MB 整包不可瘦身）、强制显著署名、许可 revocable。
- **Glow Sans**（OFL-1.1 字体 + MIT 构建代码）：唯一值得 A/B 的展示位候选，中宫更紧、更几何、贴 Manrope；但仓库 2023-08-27 已归档、无可变轴、仅 OTF（SC Normal 整包 64.3 MB），需 cn-font-split 自建分片，+2–4 MB。只用于 ≥16px 展示位，P2 设计拍板。
- **LXGW WenKai Screen**：备注区情绪字体候选（≥14px），许可有「web 子集可保留保留名但不得作为可安装桌面字体分发」的附加条款，桌面内嵌属灰区——要么原样引 npm 单变体 CSS，要么自裁改名。四个变体 CSS 声明**同一个 font-family 且都是 400**，同时引入会互相覆盖，只能引一个；`style.css` 会把 388 片 19.3 MB 全拉进产物。
- **Chiron Hei HK**：OFL 干净、格式齐全，但港式字形用于简体 UI 是内容正确性问题，排除。

### 3.4 等宽与数字：修回退链，不换字体

实测 Geist Mono 的 CJK 覆盖为 0，回退位的 Cascadia Code 也是 0，Consolas 也无 CJK——`formatParsedDue` 输出的「年/月/日/今天/明天」现在一路掉到系统字体。**P0 一行修复**：把 `Noto Sans SC Variable` 插到 Cascadia 之前（它已在 `main.tsx:4` 导入）。全 `src` 的 `var(--font-mono)` 实为 **11 处**（调研写 23，已纠正）。

**Maple Mono CN 是本轮唯一实测严格 2:1 的方案**（汉字 advance 1200 / 拉丁 600 / upm 1000），中文时间戳不再半格错位。列为 P2 备选：自裁 subset（26 个时间戳汉字只落在 12 个分包共 348,468 B，pyftsubset 可再压一个数量级），代价是 CN 中文是圆角的 Resource Han Rounded、与正文方角不同，且无可变轴。合规上必须带 CyanoHao 版权行 + Adobe Portions 行（RFN 'Source'，但 "Maple Mono CN" 不含 Source，不触发）。

其余等宽不替换：JetBrains Mono 的 fontsource 包实测只有 calt/ccmp/frac/locl/mark（**没有 zero/ss/cv/tnum**，上游宣传的字符替换调不动），包内字体 Version 2.211 落后上游 v2.304；Commit Mono 连字默认关但静态无 450、2023-12 后停更；IBM Plex Mono latin 400 仅 14,708 B 最小但无可变轴；Iosevka latin 400 高达 984,084 B 且包内 22.1.2 落后上游 v34.9.1 十几个大版本。

### 3.5 动效：只做确认，三条明确不做

**采纳：**
- **对勾 `pathLength` 描边**（120ms 微确认）替换现在的 scale 0.4→1 弹入。缩放弹入是装饰性的「跳一下」，描边是语义性的「划掉」；且 scale 在 100/125/150/200% 显示缩放下产生半像素模糊，描边不会——这正是 smoke 已在测的那组缩放。**reduced-motion 必须手动补**：`MotionConfig reducedMotion="user"` 管不到 `pathLength`（它不是 transform），要 `useReducedMotion()` 把 initial 直接设 1。
- **spring → tween**：`TaskItem.tsx:42` 的 `{ stiffness: 420, damping: 40 }` ζ = 40/(2√420) ≈ 0.976 仍是欠阻尼；设计硬约束「密集列表禁止回弹过冲」，tween + `--ease-out` 是零过冲的确定解。
- **原生 CSS 一次性入场/退场**（P2 可选）：`@starting-style` + `transition-behavior: allow-discrete` 让 toast 退场播完再卸载，少一套与 AnimatePresence 抢卸载时机的状态机。Chromium 156 内置，零依赖零义务（SPDX NONE）。`interpolate-size` 暂无落点（项目没有折叠交互），留作将来。

**明确不做（理由都是实测）：**
- **AnimateView**：`motion/react-animate-view` 入口确实存在、已脱离 Motion+ 付费墙，但它解决的「退场播完再卸载」AnimatePresence 已经做到，Polaris 没有跨视图共享元素，收益为零；代价非零——源码 grep `reducedMotion` 0 命中（MotionConfig 管不到它），`globals.css:3346` 的 `*, *::before, *::after` 也覆盖不到 `::view-transition-*` 伪元素树，主题切换与视图过渡同帧还会看到两套画布交叉淡化。
- **`spring()` 生成 CSS `linear()` 缓动**：本机 motion 14.12.0 的四个公共入口（`framer-motion/dist/{dom,index,mini,dom-mini}.d.ts`）**都不导出 `spring`**，脚本跑不起来。另核验轮实测 `spring(0.2, 0)` 输出是 **400ms 不是调研写的 200ms**，照抄会超出 320ms 硬约束。`--ease-out` 已够，不加第二条曲线。
- **tw-animate-css**：唯一划算的 accordion 折叠在项目里没有落点（已完成分组是常驻 section）；`blur-in-*` 违反「内容面禁止毛玻璃」；`caret-blink` 是无限循环（违反硬约束 5）；库本身 0 处处理 reduced-motion；README 警告 v2 破坏性变更。

Lottie / dotLottie / Rive / GSAP / animate.css / auto-animate / animejs / SMIL 全部排除，理由见 8.2/8.3。

### 3.6 纹理与背景：先挂载，再谈改

**关键事实：`.noise` 与 `.aurora` 都是死 CSS。** 规则在 `globals.css:511-530`，但全 `src/` 的 ts/tsx/html 里 `aurora|noise` 0 命中（本轮再次 Grep 复核），没有任何元素挂载。所以：

- **噪点**：若设计确认要颗粒层，先在 `App.tsx` 的 `.app-shell` 内挂 `<div className="noise" aria-hidden="true" />`，再把 data URI 加一条 `feColorMatrix type='saturate' values='0'` 去饱和（现版本输出彩色噪声，浅色主题下颗粒带彩边会干扰 teal 纯度）。强度继续由 `--noise-opacity` 单令牌控制（暗 0.032 / 暮蓝 0.03 / 浅 0.018），主题切换只改 opacity，栅格缓存不失效。素材是自绘 feTurbulence（MDN 代码片段 CC0），零第三方义务。
- **aurora 保持不挂载**：它的第二层是 `rgba(var(--accent-2-rgb), 0.15)` 铺满窗口右上，真挂上去就违反「teal→violet 渐变只属于星标记和空状态构图」。不要按调研去换 mesh SVG。若将来清理，`.aurora` 规则必须与六套主题里的 `--aurora-opacity` / `--aurora-c-rgb` 一起删（只删 `:root` 会让注册表校验失败）。
- **几何底纹自绘即可**：网格/点阵本来就是两条渐变，自己写零依赖、零署名、六主题自动跟随，「从 css-pattern.com 复制再改色」是多余步骤。只有 Topography 这类**非渐变形状**才需要下载素材走 mask 方案——那时首选 Pattern Monster（MIT），不选 Hero Patterns（CC BY 署名三件套）。
- **`--inner-highlight` 禁令**：新增任何装饰层不许写 `box-shadow: inset 0 1px 0 var(--inner-highlight)`。它在浅色家族是 90% 白，铺在饱和 `--accent` 填充上会产生近白描边；`src/main/index.ts:1408` 的冒烟断言会扫描每一个可聚焦元素，背景色与 `--accent` 相差 ≤6 且含 inset 直接判失败。

### 4.1 现状缺口：现在就在欠的账（与新增素材无关）

```tsx
import type { ReactNode, SVGProps } from 'react'

/** 与 lucide-react 调用点兼容：size / strokeWidth / className / style / aria-* 原样可用。 */
export type IconProps = Omit<SVGProps<SVGSVGElement>, 'children'> & {
  size?: number | string
}

/**
 * 第二套图标库的唯一接入点。几何数据由 scripts/make-icons.mjs 在构建期生成，
 * 运行时不新增任何图标包。
 *
 * mode='fill'：路径已填充化（Phosphor / MingCute / Radix）。描边粗细不可调，
 *   要改视觉重量只能换 weight 重新生成，写 stroke-width 是空操作。
 * mode='stroke'：线性几何（Tabler / Iconoir），粗细由 --icon-stroke 统一控制。
 *
 * 颜色一律 currentColor：六套主题靠父级 color 继承，零颜色覆盖。
 * 无障碍：没传 aria-label / aria-labelledby 就自动 aria-hidden，
 * 传了就 role="img"，纯图标控件仍要求外层按钮自带 aria-label。
 */
export function defineIcon(
  name: string,
  viewBox: string,
  mode: 'fill' | 'stroke',
  children: ReactNode
) {
  function Glyph({ size = 16, className, ref, ...rest }: IconProps) {
    const labelled = Boolean(rest['aria-label'] || rest['aria-labelledby'])
    return (
      <svg
        ref={ref}
        xmlns="http://www.w3.org/2000/svg"
        viewBox={viewBox}
        width={size}
        height={size}
        fill={mode === 'fill' ? 'currentColor' : 'none'}
        stroke={mode === 'fill' ? 'none' : 'currentColor'}
        strokeLinecap="round"
        strokeLinejoin="round"
        focusable="false"
        role={labelled ? 'img' : undefined}
        aria-hidden={labelled ? undefined : true}
        className={`p-icon p-icon-${mode} p-icon-${name}${className ? ` ${className}` : ''}`}
        {...rest}
      >
        {children}
      </svg>
    )
  }
  Glyph.displayName = name
  return Glyph
}
```

```js
// 生成 src/renderer/src/components/icons/glyphs.tsx —— 生成物入库，不要手改。
// 素材：@phosphor-icons/core 2.1.1（MIT），devDependency，不进安装包。
// 用法：node scripts/make-icons.mjs
import { mkdir, readFile, writeFile } from 'node:fs/promises'
import { dirname, join } from 'node:path'
import { fileURLToPath } from 'node:url'

const root = join(dirname(fileURLToPath(import.meta.url)), '..')
const assets = join(root, 'node_modules/@phosphor-icons/core/assets')
const outDir = join(root, 'src/renderer/src/components/icons')
const outFile = join(outDir, 'glyphs.tsx')

// weight 目录的文件名规则：regular 无后缀，其余一律带 -<weight> 后缀。
const GLYPHS = [
  { name: 'Tray', weight: 'regular', file: 'tray' },
  { name: 'TrayArrowDown', weight: 'regular', file: 'tray-arrow-down' },
  { name: 'TrayArrowUp', weight: 'regular', file: 'tray-arrow-up' },
  { name: 'RepeatOnce', weight: 'regular', file: 'repeat-once' },
  { name: 'CircleGlyph', weight: 'regular', file: 'circle' },
  { name: 'CheckCircleGlyph', weight: 'fill', file: 'check-circle' },
  { name: 'FlagGlyph', weight: 'fill', file: 'flag' }
]

const blocks = []
for (const glyph of GLYPHS) {
  const suffix = glyph.weight === 'regular' ? '' : `-${glyph.weight}`
  const file = join(assets, glyph.weight, `${glyph.file}${suffix}.svg`)
  const svg = await readFile(file, 'utf8')
  if (/<(script|style|foreignObject|animate)\b/i.test(svg)) {
    throw new Error(`${file} 含不可信节点，拒绝生成`)
  }
  const viewBox = /viewBox="([^"]+)"/.exec(svg)?.[1]
  if (!viewBox) throw new Error(`${file} 缺少 viewBox`)
  const paths = [...svg.matchAll(/<path\b[^>]*\bd="([^"]+)"/g)].map((m) => m[1])
  if (paths.length === 0) throw new Error(`${file} 没有 path`)
  const body = paths.map((d) => `    <path d="${d}" />`).join('\n')
  blocks.push(
    `export const ${glyph.name} = defineIcon('${glyph.name}', '${viewBox}', 'fill', (\n` +
      `  <>\n${body}\n  </>\n))`
  )
}
```

### 8.4 找不到合适开源选项的类别（诚实说明）

- **中文 UI 黑体替换**：没有比 Noto Sans SC 更优且法律干净的选项——MiSans 禁分发、HarmonyOS 禁修改、Glow Sans 归档、Chiron Hei HK 港式、文楷是楷体、新晰黑是 IPA。**保留现状是结论，不是妥协。**
- **持续循环的装饰动画素材**：开源生态（Lottie/Rive）的典型用法就是循环，与设计硬约束 5 正面冲突——不存在「合适的」选项。替代：自绘内联 SVG + motion pathLength 一次性动效。
- **tray 语义图标**：lucide 缺、只有 Phosphor Icons 有，已用 vendored 字形解决，不需要整库。
- **中文等宽 2:1**：Maple Mono CN 是唯一实测达标者，但需自裁 + 双署名，列为备选而非默认。

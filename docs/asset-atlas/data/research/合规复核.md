# 零、先修一个已经存在的缺口（不是候选素材的问题）

实测 `E:\project\Polaris-Todo\dist\win-unpacked\resources\app.asar`（0.2.1 产物）：

原因链：四款字体是 `devDependencies`，electron-builder 打包时剪掉；Vite 只 emit CSS 引用到的 woff2，不会 emit 包内的 `LICENSE`。而 `node_modules/@fontsource-variable/*/LICENSE` 里**是有完整 OFL 全文 + 版权行的**（我读过：Inter「Copyright 2016 The Inter Project Authors」、Manrope「Copyright 2019 The Manrope Project Authors」、Geist Mono「Copyright 2024 The Geist Project Authors」、Noto Sans SC「Google Inc.」）——它们只是没进包。

**判定**：现状属于「再分发 OFL 字体但未随附许可证文本」。OFL FAQ 1.10 确实给了一个窄例外（"a font is embedded in a document or bundled within a program" 时可不附全文，元数据里放链接即可），但 FAQ 同时明确 *strongly discouraged*；且本机没有 fontTools/brotli，**无法验证 fontsource 的 woff2 二进制里是否保留了 nameID 0/13 版权与许可字段**，所以不能拿「二进制元数据」当唯一依据。→ **必须补 NOTICE，这条与是否引入新素材无关，现在就欠着。**

另外三个打包层面的坑（都来自实读 `E:\project\Polaris-Todo\electron-builder.yml`）：

1. `files` 里有 `!*.md` → **README.md 不进包**。任何「署名写进 README」的方案对最终用户无效。
2. `files` 里有 `!build/**/*` → 调研建议的 `build/THIRD_PARTY_NOTICES.txt` **也不会进包**，且当前没有配 `extraResources`。
3. 仓库根目录**没有 LICENSE 文件**（`package.json` 写 `"license": "MIT"`）。对外分发的 MIT 应用建议补上。
4. 附带：`polaris-packaged-debug.log` 被打进了 asar，建议加进排除列表（非合规问题）。

# 一、分发模型基线（NSIS + asar = 再分发，逐协议义务）

| 协议 | 能否随包再分发 | 义务 | 署名放哪 |

# 三、OFL 子集化 × Reserved Font Name：专项结论

**抓到的规则原文**（`openfontlicense.org/ofl-faq`，配合各仓库 OFL 条件 3）：

- 条件 3：*"No Modified Version … may use the Reserved Font Name(s) … This restriction only applies to the primary font name as presented to the users."*
- **FAQ 2.6**：*"Removing any parts of the font when delivering a webfont to a browser, including unused glyphs and smart font code, is considered modification."* → **子集化 = 修改**，*"would not normally allow the use of RFNs"*。
- **FAQ 2.2 / 2.2.1**：换格式原则上算修改；**只有「原始数据除 WOFF 压缩外完全不变、且元数据原样保留或整体省略」**才不算修改。
- **FAQ 2.7 / 2.8**：想保留 RFN，必须满足 **Functional Equivalence**——完整字符集、同样的 smart font 行为、无视觉退化、保留作者/许可/RFN/指回原项目的元数据。**按字裁到几十个汉字，字符集必然不完整 → 不可能满足 FE。**
- **FAQ 5.3**：RFN 约束「字体菜单名及其它在文档中指定字体的机制」→ **CSS `font-family` 也算**，不是只改 name 表就够。
- **FAQ 1.4 / 1.5 / 3.3**：字体随软件包一起分发/售卖**明确允许**，原版与派生版都行；只禁止「字体单独售卖」。→ **Polaris 免费 NSIS 分发，条件 1 完全不触发，将来收费也不触发。**

### 落到 Polaris 的每一项计划

## 4.1 Hero Patterns（CC BY 4.0）怎么署名才算数

```tsx
import type { ReactNode, SVGProps } from 'react'

/** 与 lucide-react 调用点兼容：size / strokeWidth / className / style / aria-* 原样可用。 */
export type IconProps = Omit<SVGProps<SVGSVGElement>, 'children'> & {
  size?: number | string
}

/**
 * 第二套图标库的唯一接入点。几何数据由 scripts/make-icons.mjs 在构建期生成，
 * 运行时不新增任何图标包。
 *
 * mode='fill'：路径已填充化（Phosphor / MingCute / Radix）。描边粗细不可调，
 *   要改视觉重量只能换 weight 重新生成，写 stroke-width 是空操作。
 * mode='stroke'：线性几何（Tabler / Iconoir），粗细由 --icon-stroke 统一控制。
 *
 * 颜色一律 currentColor：六套主题靠父级 color 继承，零颜色覆盖。
 * 无障碍：没传 aria-label / aria-labelledby 就自动 aria-hidden，
 * 传了就 role="img"，纯图标控件仍要求外层按钮自带 aria-label。
 */
export function defineIcon(
  name: string,
  viewBox: string,
  mode: 'fill' | 'stroke',
  children: ReactNode
) {
  function Glyph({ size = 16, className, ref, ...rest }: IconProps) {
    const labelled = Boolean(rest['aria-label'] || rest['aria-labelledby'])
    return (
      <svg
        ref={ref}
        xmlns="http://www.w3.org/2000/svg"
        viewBox={viewBox}
        width={size}
        height={size}
        fill={mode === 'fill' ? 'currentColor' : 'none'}
        stroke={mode === 'fill' ? 'none' : 'currentColor'}
        strokeLinecap="round"
        strokeLinejoin="round"
        focusable="false"
        role={labelled ? 'img' : undefined}
        aria-hidden={labelled ? undefined : true}
        className={`p-icon p-icon-${mode} p-icon-${name}${className ? ` ${className}` : ''}`}
        {...rest}
      >
        {children}
      </svg>
    )
  }
  Glyph.displayName = name
  return Glyph
}
```

**`--inner-highlight` 的陷阱（新增素材必须遵守）：**

新增的任何装饰层都**不许**写 `box-shadow: inset 0 1px 0 var(--inner-highlight)`。它在浅色家族是 90% 白，铺在饱和 `--accent` 填充上会在顶边产生近白描边。`src/main/index.ts:1408` 的冒烟断言会扫描**每一个**可聚焦元素，只要背景色与 `--accent` 相差 ≤6 且 `box-shadow` 含 `inset`，直接判失败。图案层、图标、星标记衬底一律 `background-color` + `mask`，不加任何 inset。

**关于 `.aurora`：** 它现在没挂载，而它的第二层是 `rgba(var(--accent-2-rgb), 0.15)` 铺满窗口右上——真挂上去就违反"teal→violet 渐变只属于星标记和空状态构图"。**建议保持不挂载**，不要按清单去换成 mesh SVG。要清理的话，`.aurora` 规则 + 六套主题里的 `--aurora-opacity` / `--aurora-c-rgb` 必须一起删（只删 `:root` 会让注册表校验的 `var()` 定义检查失败）。

**为什么把 spring 换成 tween：** ζ = 40/(2√420) ≈ 0.976，仍是欠阻尼。设计硬约束写的是"密集列表禁止回弹过冲"，tween + `--ease-out` 是零过冲的确定解。

对勾的具体写法（替换 `TaskItem.tsx:51-64`）：

```tsx
{task.completed && (
  <motion.svg
    viewBox="0 0 24 24"
    width={12}
    height={12}
    fill="none"
    aria-hidden="true"
    style={{ stroke: 'var(--check-mark)' }}
  >
    <motion.path
      d="M20 6 9 17l-5-5"
      initial={{ pathLength: reduced ? 1 : 0 }}
      animate={{ pathLength: 1 }}
      transition={{ duration: 0.12, ease: [0.22, 1, 0.36, 1] }}
      style={{ strokeWidth: 2.6, strokeLinecap: 'round', strokeLinejoin: 'round' }}
    />
  </motion.svg>
)}
```

组件顶部加 `const reduced = useReducedMotion()`（从 `motion/react` 导入，已核实导出）。注意这里的 `strokeWidth` 必须写在 `style` 里而不是属性上，否则会被 `.task-check .p-icon` 的 CSS 规则盖掉。

**明确不做的三条：**

- **`AnimateView`**：`motion/react-animate-view` 确实存在（`dist/react-animate-view.d.ts` → `framer-motion/animate-view`，导出 `AnimateView`）。但它解决的是"退场播完再卸载"，而 `AnimatePresence` 已经做到了；Polaris 没有跨视图共享元素，收益为零。代价非零：`MotionConfig` 管不到它，`globals.css:3346` 的 `*, *::before, *::after` 也覆盖不到 `::view-transition-*` 伪元素树，得手写一条媒体查询；主题切换与视图过渡同帧还会看到两套画布交叉淡化。**不做。**
- **`spring()` 生成 `--ease-spring`**：本机 motion 14.12.0 **没有这个导出**，清单里的脚本跑不起来。而且 `--ease-out` 已经是强调曲线，再加一条弹性曲线对"动效只做确认"没有增益。**不做。**
- **`tw-animate-css`**：唯一划算的 accordion 折叠，Polaris 现在根本没有折叠交互（`TaskView.tsx:147-161` 的已完成分组是常驻 section）。这是新增功能不是改进，且 `blur-in-*` 系列违反"内容面禁止毛玻璃"。**不做。**

`LazyMotion + m` 瘦身放到 P2，且**必须先量**：当前 `out/renderer/assets/index-*.js` 是 1,367,558 B，改完不变小就不值得动 6 个文件。真要改只能用 `domMax`（`layout` / `layoutId` 不在 `domAnimation` 里），`strict` 会在漏改时抛错。
